# Annie Zhang — personal website

A lightweight, responsive one-page personal site built with plain HTML and CSS for GitHub Pages.

## Personalize this scaffold

- The LinkedIn link points to your supplied profile.
- The provided resume PDF is included at the repository root as `resume.pdf`; the resume button opens it.
- Replace the sample About copy and project cards with your own details, work, and links.
- The GitHub profile links point to [zhangium](https://github.com/zhangium).

## Visitor metrics

GitHub's repository **Insights → Traffic** shows repository visitors and page views for the past 14 days. Those numbers describe visits to the repository on GitHub, not visits to the published Pages website. To count website visitors, choose a web analytics provider and add its site ID/script to `index.html`.
