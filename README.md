# Annie Zhang — Personal Website

A lightweight, responsive one-page portfolio built with HTML, CSS, and JavaScript for GitHub Pages.

## Site content

- About section with a short introduction
- Selected work highlights based on experience in the resume
- Resume PDF at the repository root, linked from the site
- LinkedIn and GitHub profile links

Update the About copy and project descriptions as the portfolio evolves.

## Visitor metrics

GitHub's repository **Insights → Traffic** shows visitors and page views for the repository over the past 14 days. These are repository visits, not visits to the published Pages website. Website visitor analytics require a separate provider and its site ID/script in `index.html`.
